# Frontend – Sales and Purchases Management System

This directory contains the frontend of the Sales and Purchases Management System.

The frontend is developed using Angular and TypeScript. It provides the user interface through which administrators interact with the application and manage business operations.

## Technologies Used

- Angular
- TypeScript
- Tailwind CSS
- Flowbite

## Main Responsibilities

- Display the administration dashboard.
- Provide interfaces for managing clients and suppliers.
- Manage products and categories.
- Provide sales and purchase management interfaces.
- Communicate with the backend REST API.
- Provide authentication and profile interfaces.

## Installation and Execution

```bash
npm install
ng serve
```

The application is available at:

http://localhost:4200
